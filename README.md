# R_CS5301
CS_5301 - Programming Foundations for Data Analytics @University of Houston-Downtown. Fall 2025

The course provides essential foundations of the R programming language for developing powerful and reusable data analysis models. The students will get hands-on training on writing programs to facilitate discoveries from data. The topics include data import/export, data types, control statements, functions, and data visualization.

The focus of this repository is to track and reference scripts for better understanding of R and Data Analytics/Vizualization.
